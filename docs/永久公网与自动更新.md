# 永久公网地址与自动更新

这份说明解决两个重复劳动：

1. 不再每次手动开 Cloudflare 临时隧道、再复制一个会变的网址。
2. 不再每次更新都先卸载、再重新下载安装包。

## 一、公网地址：一次配置，永久使用

应用启动时会**自动**按下面顺序建立公网入口，不需要点“开启隧道”：

| 优先级 | 方式 | 地址 | 是否永久 |
| --- | --- | --- | --- |
| 1 | Tailscale Funnel | `https://<设备名>.<你的 tailnet>.ts.net` | **永久**，重启电脑也不变 |
| 2 | Cloudflare Quick Tunnel | `https://<随机名>.trycloudflare.com` | 每次启动会变 |

### 一次性安装 Tailscale（约 3 分钟）

在 Windows 主机上，直接双击项目根目录或桌面上的 **`启用永久公网.cmd`**，脚本会自动安装 Tailscale、拉起登录，并提示重启应用。也可以手动执行：

```powershell
winget install --id Tailscale.Tailscale -e
```

安装完成后打开 Tailscale，登录你的账号（可用 Google/Microsoft/GitHub 账号）。确认状态为 `Running`：

```powershell
tailscale status
```

然后在 Tailscale 管理后台的 **DNS** 页面确认已启用 **HTTPS Certificates**，在 **Access Controls** 里允许 Funnel（个人版默认可用）。之后**不需要再手动执行任何命令**：Monet Chat 启动时会自己执行 `tailscale funnel` 并把永久地址写进邀请二维码。

> 只有第一次需要登录。以后开机、重启、换 Wi-Fi，地址都不变。
> 如果 Tailscale 不可用（未安装/未登录/Funnel 没开），应用会自动退回 Cloudflare 临时隧道，并在邀请弹窗里明确标注“临时地址”。

### 手机端

- 安卓 APK 首次安装时填服务器地址：有永久地址就填 `https://<设备名>.<tailnet>.ts.net`，同一 Wi-Fi 也可以填 `http://<电脑局域网 IP>:4173`。
- 之后只需要扫 Windows 端的邀请二维码，不需要再改服务器地址。

### 为什么不能完全不用服务器

P2P 去掉的是“消息中继”，不是“房间发现 + NAT 穿透”。WebRTC 仍需要一次信令交换；Tailscale Funnel 只是把这一步变成一个永久、可访问的 HTTPS 入口。消息和文件仍然只走两台设备之间的加密 DataChannel。

## 二、自动更新

### Windows（安装版 / 便携版）

设置 → 关于 → **检查更新**：

1. 应用会向本机服务查询 GitHub 最新 Release，不依赖浏览器能否打开 GitHub。
2. 发现新版本后，桌面版会下载 Setup 并自动运行；安装器覆盖旧版本，**不需要手动卸载**。
3. 更新失败时会给出原因，也可以点“打开发布页”手动下载。

应用启动 15 秒后会在后台静默检查一次；有新版本时只弹一条提示，不会自动下载 100MB+ 的包。

> 当前 EXE 未做代码签名，Windows SmartScreen 可能提示“未知发布者”。这是签名证书问题，不是安装包损坏。

### Android

设置 → 关于 → **检查更新**：

1. 检查 GitHub Release 中的最新 APK。
2. 点击“下载 APK”，优先从当前服务器/局域网下载，失败再走 GitHub。
3. 下载完成后点开 APK，Android 会覆盖安装并保留聊天记录，**不需要先卸载**。

Android 系统不允许应用在无提示的情况下静默安装 APK；最后一步“是否安装”必须由你点确认，这是系统安全限制。

### Linux

当前 Linux 包是免安装 tar.gz。设置 → 关于 → 检查更新会打开发布页；替换解压目录即可，数据在用户目录的浏览器/应用存储中。

## 三、常见问题

**Q：Tailscale 显示未登录，应用还是能用吗？**
能。会自动退回 Cloudflare 临时地址，功能和永久地址完全一样，只是网址每次启动会变。

**Q：永久地址打不开？**
先在电脑上访问 `https://<设备名>.<tailnet>.ts.net/api/health`，确认返回 `{"ok":true,...}`。若 Tailscale 管理后台没开 HTTPS/Funnel，按提示开启一次即可。

**Q：更新会丢聊天记录吗？**
不会。记录在 IndexedDB（Windows 在用户数据目录，Android 在应用私有目录），覆盖安装不会清除。仍建议定期“导出全部聊天”。

**Q：能不能完全自动、连提示都不点？**
Windows 安装版可以做到下载后自动运行安装器；Android 受系统限制，最后一步安装确认必须人工点。公网地址在 Tailscale 配置完成后完全自动。
